# Course Scheduling

Here are instances and code for the 2nd International
Timetabling Competition ([ITC
2007](http://www.cs.qub.ac.uk/itc2007/)).

The `datasets` directory also contains the program
`benchmark_my_linux_machine` that the competition provides.
It is a 32-bit Linux executable, and the tests use it to
estimate how much time the solver may spend on a machine.
